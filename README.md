## Portugues

### Sobre
Simulacao do fractal Triangulo de Sierpinski com multiplas abordagens de implementacao em JavaScript. Inclui versao original, versao explicada com comentarios e versao refatorada.

### Tecnologias
- JavaScript
- HTML Canvas

### Arquivos
- `script.js` - Implementacao principal
- `scriptExplicado.js` - Versao com comentarios explicativos
- `scriptRefactGPT.js` - Versao refatorada
- `functionTest.js` - Testes das funcoes

### Como rodar
Abra o arquivo `index.html` no navegador.
